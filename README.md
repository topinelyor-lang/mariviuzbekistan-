# MARIVI — сайт-витрина

Introduction-сайт бренда MARIVI: мебель ручной работы с сюзане и адрасом, Ташкент.
Главное на сайте — 3D-модели мебели: их можно вращать, а на телефоне — открыть в AR.

Статический сайт без сборки: HTML + CSS + [`<model-viewer>`](https://modelviewer.dev).

## Структура

```
site/                 ← то, что публикуется (GitHub Pages)
  index.html          главная: hero, витрина Ko'rgazma, заказ
  models/             оптимизированные 3D-модели (1–3 МБ каждая)
  prototypes/         ранние варианты дизайна A и B, для истории
source-models/        оригинальные модели 20–35 МБ (НЕ в git, только локально)
scripts/optimize.mjs  сжатие source-models → site/models
dev/compare.html      сравнение оригинал / оптимизация, бок о бок
.github/workflows/    автодеплой site/ на GitHub Pages
```

## Запуск локально

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Откроется `http://127.0.0.1:8766/site/`.
Сравнение качества моделей: `http://127.0.0.1:8766/dev/compare.html`.

> Двойной клик по `index.html` не сработает: браузер не грузит модели с `file://`. Нужен локальный сервер.

### Добавить или обновить модель

1. Положите оригинальный `.glb` в `source-models/` с именем `m8.glb` (или замените существующий).
2. Выполните:
   ```bash
   npm run optimize            # все модели
   npm run optimize:one m8     # только одну
   ```
3. Результат появится в `site/models/`. Добавьте запись в массив `items` в `site/index.html`.
4. Увеличьте номер версии моделей `MODELS_V` в `site/index.html`. Иначе браузеры до 10 минут будут показывать старые модели из кэша.

Скрипт собирает две версии каждой модели: `site/models/` для компьютеров (текстуры 2048 px) и `site/models/mobile/` для телефонов (1024 px, примерно вдвое меньше треугольников, 1–2 МБ). Сайт сам выбирает лёгкую версию для сенсорных экранов, узких окон и устройств с малым объёмом памяти. Модели грузятся по очереди: сначала первый экран, потом витрина.

Пока 3D-модель загружается, вместо неё сразу видна картинка-превью из `site/posters/` (20–50 КБ, тот же ракурс). После `npm run optimize` пересоберите превью: запустите `npm run dev`, локальный сервер приёма картинок (`python3 scripts/poster-save-server.py site/posters`) и откройте `http://127.0.0.1:8766/dev/posters.html`.

### Реальные размеры и AR

AR показывает мебель в натуральную величину и ставит её точно на пол. При оптимизации каждая модель:

- масштабируется до реального размера (1 единица = 1 метр);
- ставится ножками ровно на y = 0. Если под ножками есть случайные «осколки» геометрии, скрипт их не считает полом, иначе предмет висел бы в воздухе;
- центрируется по площади опоры.

Размер задаётся в [`models.json`](models.json):

| Поле | Что значит |
|---|---|
| `heightCm` | точная общая высота от бренда (главнее остальных) |
| `seatCm` | высота сиденья; общая высота считается по измеренной доле сиденья в модели |
| `topCm` | для предметов, на которые садятся сверху (оттоманка) — общая высота |

Пока точных размеров нет, у кресел и банкетки стоит `seatCm: 44` (обычная высота сиденья), у оттоманки `topCm: 44`. Проверить, какие размеры получатся, можно без пересборки: `node scripts/analyze-models.mjs`.

AR работает так:

- **Android** — открывается Google Scene Viewer (встроен в Android через приложение Google). Он быстро находит пол, даже глянцевую плитку, ставит предмет в натуральную величину; жесты: перетащить, повернуть двумя пальцами, щипок — размер (у 100% «прищёлкивается» к натуральному). Scene Viewer читает отдельный файл из `site/models/ar/` (JPEG + Draco: WebP он не понимает). Если Scene Viewer нет, следующее нажатие открывает AR в браузере (WebXR) с нашими кнопками «Повернуть / Развернуть / Увеличить».
- **iPhone / iPad** (iOS 12+) — AR Quick Look от Apple, файл USDZ собирается на телефоне из модели.
- **Компьютер** — кнопка показывает QR-код, который открывает этот же экспонат на телефоне.

## Публикация на GitHub Pages

1. Отправьте код в `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. После каждого push в `main` сайт обновляется сам. Адрес появится во вкладке **Actions** и в **Settings → Pages**.
